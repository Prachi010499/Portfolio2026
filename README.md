# Prachi Pancholi — Portfolio

Personal portfolio, built as a static site and hosted on GitHub Pages.

## Structure
- `index.html` — home page
- `noise/`, `upstox/`, `healthkart/`, `reown/`, … — case-study pages
- `explore/`, `about-us/` — sections
- `css/`, `js/` — shared styles and scripts

## Local preview
```bash
python3 -m http.server 4599
```
then open http://localhost:4599
